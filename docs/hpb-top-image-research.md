# HPB トップ画像（メイン画像）のリサーチ手順

自社の Hot Pepper Beauty 掲載ページのトップ画像を作り直すにあたり、
競合店の画像を「感覚」ではなく「並べて比較できる形」で集めるための手順書。

前提：HPB のトップ画像は、単体で見るものではなく **検索結果一覧にサムネイルとして並ぶ**もの。
ユーザーが1枚に使う時間は1〜2秒。したがってリサーチの単位も「1店舗の写真」ではなく
**「自店が実際に並ぶ一覧ページ」**にする。

---

## STEP 1. 競合を「一覧ページのURL」で機械的に定義する

「なんとなく近そうな店」ではなく、**自店と同じ検索結果に出てくる店**が競合。
HPB の一覧URLは `エリアコード × ジャンルコード` で固定できるので、これをブックマークする。

### URL の構造

```
https://beauty.hotpepper.jp/genre/<ジャンルコード>/stc<駅コード>/     ← 駅単位
https://beauty.hotpepper.jp/genre/<ジャンルコード>/pre28/city20400000/ ← 西宮市単位
```

### エリアコード（自店＝西宮市門戸東町）

| エリア | コード |
| --- | --- |
| 門戸厄神駅 | `stc3240950` |
| 西宮北口駅 | `stc3241025` |
| 西宮駅（阪神） | `stc3240878` |
| 西宮駅（JR） | `stc3240974` |
| 西宮市全体 | `pre28/city20400000` |

### ジャンルコード

| ジャンル | コード |
| --- | --- |
| 整体・矯正 | `kgkw011` |
| ダイエット（エステ） | `kgkw112` |
| 痩身 | `kgkw044` |
| マッサージ | `kgkw004` |
| 揉みほぐし | `kgkw102` |
| フェイシャル | `kgkw043` |

### 最低限見るべき6ページ

1. 門戸厄神駅 × ダイエット … `/genre/kgkw112/stc3240950/`
2. 西宮北口駅 × 痩身 … `/genre/kgkw044/stc3241025/`
3. 西宮北口駅 × 整体・矯正 … `/genre/kgkw011/stc3241025/`
4. 西宮市 × 整体・矯正 … `/genre/kgkw011/pre28/city20400000/`
5. 西宮市 × マッサージ … `/genre/kgkw004/pre28/city20400000/`
6. 西宮駅 × 整体・矯正 … `/genre/kgkw011/stc3240878/`

各ページで並び順を **「おすすめ順」と「口コミ件数順」の2回**見る。
おすすめ順＝掲載プランの強い店（＝予算で殴ってくる相手）、
口コミ順＝実力で選ばれている店（＝画像も練られている確率が高い）。
それぞれ上位20件が実質の競合母集団。

## STEP 2. 集め方のルールを先に決める

ここを決めずに集めると後で比較できなくなる。

- **必ずスマートフォン表示で見る。** HPB流入の大半はスマホで、一覧のサムネイルは小さい。
  PCの大きな画像で判断すると必ず読み違える。
- **一番重要なのは「一覧ページのスクリーンショット」。**
  自店が写り込んだ状態で撮る。1枚単体で良く見える画像でも、並べると埋もれる／浮くが分かる。
  一覧スクショは各ページ2〜3枚（上位20件が入るまでスクロールして撮る）。
- 気になった競合は **店舗トップの写真を1枚目から5枚目まで**見る。
  1枚目だけでなく「2枚目以降に何を置いているか」が、その店の勝ち筋の順番を表す。
- ファイル名の型：`<一覧ページ名>_<順位>_<店名>.png`
  例）`門戸厄神ダイエット_03_◯◯サロン.png`
- 集める枚数の目安：一覧スクショ12枚＋個別サムネ30〜40枚。半日で終わる量に留める。

> ⚠️ 集めた画像はあくまで**構成・訴求の分析用**。写真そのものやコピーの流用はしない。

---

## STEP 3. 採点シートで言語化する

スプレッドシートに1行1店舗で以下を埋める。「良かった／悪かった」ではなく
**事実を分類する**のが目的。

| 列 | 記入内容 |
| --- | --- |
| 店名 / 順位 / 一覧ページ | どこで何位に出ていたか |
| 被写体タイプ | 施術中／ビフォーアフター／店内・内装／スタッフ集合／外観／文字だけのバナー |
| 人物の有無 | 顔あり／顔なし（後ろ姿・パーツ）／人物なし |
| 文字の有無 | なし／短い（〜10字）／長い（帯・箇条書き） |
| 訴求内容 | 価格・クーポン／実績数値（-◯kg、◯名）／悩み（ぽっこりお腹等）／こだわり（個室・国家資格）／雰囲気のみ |
| 数字の使用 | 使っている数字をそのまま書き出す |
| 色調 | 背景の明るさ、暖色/寒色、白飛びの有無 |
| **縮小テスト** | 画像を **幅120px** に縮小して、文字が読めるか／何の店か分かるか（○△×） |
| 一言メモ | 一覧で目に留まったか、その理由 |

**縮小テストが一番効きます。** 実際の一覧サムネイルはこの程度のサイズなので、
ここで×になる画像は、どれだけ作り込んでも一覧では機能していません。

---

## STEP 4. 「多数派」と「少数派」を分けて読む

集計したら、必ずこの2つに分ける。

- **多数派の型**（例：7割が「施術中の写真＋文字なし」）
  → ユーザーの期待値。ここを大きく外すと「このジャンルの店に見えない」＝不信になる。
- **少数派で、それでも上位にいる型**（例：1〜2店だけ「-10.8kg」の数字入り）
  → 差別化の余地。効いている証拠が順位や口コミ数に出ているか確認する。

作る方針は **「多数派の型を7割守り、3割で差をつける」**。
「全部違うことをやる」は一覧の中で異物になるだけで、たいてい逆効果。

---

## STEP 5. 自社に落とし込む（手持ち素材の棚卸し）

このリポジトリの `client/public/images/` に既に使える素材がある（`docs/lp-images.md` 参照）。

| 素材 | 枚数 | トップ画像への適性 |
| --- | --- | --- |
| ビフォーアフター `ba-01`〜`ba-07` | 7 | **最有力。** -14.9kg / -10.8kg など数字が強い |
| 施術・カウンセリング `voice-01`〜`voice-12` | 12 | 多数派の型に合わせやすい。安心感 |
| こだわり `kodawari-01`〜`03` | 3 | 個室・個別プラン・全身美容整体 |
| スタッフ `staff-*` | 3 | 顔出しの信頼訴求 |
| 店舗外観 `shop-exterior` | 1 | 2枚目以降向き |
| ファーストビュー `fv.webp` | 1 | LP用。HPBは比率が違うので要トリミング |

### 注意点

- **比率が違う。** LP の画像をそのまま流用せず、HPB用に切り直す。
  推奨は概ね横長 4:3（横1024px×縦768px以上）だが、**正はサロンボードの
  アップロード画面に表示される仕様**なので、必ずそこで確認する。
- **過度な加工はNG**（HPBの掲載ガイドライン）。明るさ・コントラスト調整までに留める。
- **ビフォーアフターと数値表現は、景表法・薬機法の観点で表記に注意**が必要。
  「個人の感想です」「効果には個人差があります」等の但し書きの要否は、
  リクルートの担当者に事前確認するのが安全。ここは自己判断しない。

---

## STEP 6. 変えたら必ず効果測定する

- サロンボードの**閲覧数（アクセス数）と予約数**を、画像変更の前後で **各2週間**比較する。
- **一度に変えるのは1枚だけ。** 5枚同時に差し替えると何が効いたか永久に分からない。
- 順番は「一覧で見られる1枚目 → 店舗トップの2〜3枚目」。1枚目が閲覧数、2枚目以降が予約率に効く。

## 補足：この作業を私（Claude）に手伝わせる場合

実行環境から `beauty.hotpepper.jp` への通信はネットワークポリシーでブロックされているため、
競合ページの取得・画像のダウンロードは自動化できません。
STEP 2 で撮ったスクリーンショットをこのリポジトリか会話に添付していただければ、
STEP 3 の採点シート化と STEP 4 の分析、STEP 5 の構成案作成は代行できます。

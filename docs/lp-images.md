# LP で使う画像

このディレクトリに置いたファイルは、そのまま `https://<サイトのURL>/images/<ファイル名>` として配信され、
`client/src/pages/Home.tsx` の `ASSETS` から参照されます。

## 経緯

もともと LP の画像は 1 枚もリポジトリに入っておらず、Manus の CDN
(`https://d2xsxph8kpxj0f.cloudfront.net/...`) を直接参照していました。
その CDN が **HTTP 403 を返すようになった**ため、ビフォーアフターを含む LP 上のすべての画像が
一斉に表示されなくなりました。同じ事故を繰り返さないよう、画像はリポジトリに同梱する方式に変更しています。

## 置き方

1. 上の表のファイル名で、このディレクトリ (`client/public/images/`) に画像を置く
2. `node scripts/check-images.mjs` で不足がないか確認する
3. コミットして `main` に反映すると、GitHub Actions が自動でビルド・デプロイする

拡張子は表のとおり (`.webp` / `.png`) に合わせてください。
別の形式しか手元にない場合は、`Home.tsx` の `ASSETS` 内の拡張子も一緒に書き換えます。

サイズの目安:

- `fv.webp` … 横幅 700px 以上（LP は最大幅 700px で表示）
- `ba-01`〜`ba-07` … 横幅 700px 以上
- `voice-01`〜`voice-12` … 正方形にトリミングされるため 1:1 に近い画像が望ましい
- `staff-*` … 円形にトリミングされ、上寄せで表示される顔写真
- `reason-01`〜`reason-04` … 横幅 400px 以上
